# 🎬 TMDb Movies Analysis

An exploratory data analysis project using the **TMDb Movies Dataset** to explore movie production trends, revenue, genres, and the relationship between audience ratings, vote counts, and revenue.

The project focuses on extracting insights from movie data and presenting the findings through clear and informative visualizations using Python.

---

## 📊 Project Overview

This project analyzes TMDb movie data to answer questions such as:

* How has movie and TV series production changed over the years?
* Which movies generated the highest revenue?
* Which genres are most represented among top-grossing movies?
* Is there a relationship between movie ratings, vote counts, and revenue?

The analysis was performed using **Python, Pandas, and Matplotlib** in a Jupyter Notebook.

---

## 📈 Analysis & Visualizations

### 1. Movies vs. TV Series: Annual Production

A line chart comparing annual production trends between movies and TV series.

**Key focus:**

* Production trends over time
* Changes in the number of movies and series produced annually
* Comparison between the two categories

---

### 2. Top 5 Movies Based on Revenue

A bar chart showing the five movies with the highest revenue in the analyzed dataset.

**Visualization type:** Bar Chart

This helps identify the highest-revenue movies and compare their performance.

---

### 3. Top-Grossing Movie Genres

A pie chart visualizing the genres associated with the top-grossing movies.

**Visualization type:** Pie Chart

This provides an overview of the genre distribution among high-revenue movies.

---

### 4. Relationship Between Vote Average, Vote Count & Revenue

A scatter plot exploring the relationship between:

* Vote Average and Revenue
* Vote Count and Revenue

**Visualization type:** Scatter Plot

This analysis helps examine whether audience engagement and ratings are associated with higher movie revenue.
